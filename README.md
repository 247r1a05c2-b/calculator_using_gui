# 🧮 Tkinter Calculator (Python)

A Python-based desktop calculator application built using Tkinter.  
The calculator supports basic arithmetic as well as scientific operations through an intuitive graphical user interface.

This project is suitable for Python GUI practice, mini projects, and resume portfolios.

---

## 🚀 Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
- Percentage calculation
- Scientific operations:
  - Square (x²)
  - Square root (√)
  - Power (xʸ)
- Clear and backspace functionality
- Error handling for invalid inputs
- Clean and responsive Tkinter-based GUI

---

- Python  
- Tkinter

Scientific functions use the built-in math module
